# Privacy

Gmail Merged TXT Exporter operates locally in the user's browser.

- It accesses only pages under `https://mail.google.com/`.
- It reads visible Gmail page content only after the user starts an export.
- It does not transmit email content or metadata to any server.
- It stores only user-selected extension settings using Chrome local extension storage.
- Exported text is downloaded directly through the browser to the user's device.
