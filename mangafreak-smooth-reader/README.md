# MangaFreak Smooth Reader

Keyboard on chapter pages:
- Right Arrow: next chapter
- Left Arrow: previous chapter
- Hold Up Arrow: scroll up at configured speed
- Hold Down Arrow: scroll down at configured speed
- Enter: toggle persistent auto-scroll on/off

The extension popup changes the scrolling speed. Mouse wheel, trackpad, scrollbar dragging, middle-click scrolling, touch scrolling, Page Up/Down, Home/End, and other normal browser scrolling remain native.

The reader page itself is replaced with only the chapter images in a centered vertical strip. The site long-strip checkbox is enabled first on every chapter.
